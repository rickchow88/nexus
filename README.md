# Nexus | Premium Tech & AI News Reader
# rickchow88
# https://github.com/rickchow88/nexus

Nexus is a fast, lightweight, and visually stunning web application designed to curate the latest news in Technology and Artificial Intelligence. 

It automatically aggregates news from the HackerNews Algolia API covering major tech ecosystems (Apple, Mac OS, Linux, iPhone, iPad) and top AI models and companies (including OpenAI, Google Gemini, Anthropic, DeepSeek, Kimi, and Opencode).

## ✨ Features
- **Real-Time Tech News:** Fetches the top and most recent stories specific to the tech and AI industry.
- **High Capacity Feed:** Configured to pull up to 1,500 news articles, ensuring you never miss an update.
- **Zero Dependencies:** Built entirely with Vanilla HTML, CSS, and JavaScript. No build tools or Node.js required!
- **Premium Aesthetics:** Features a sleek "White Mode" (light theme) with smooth glassmorphism UI elements, dynamic background gradients, and micro-animations on hover.
- **Responsive Design:** Looks great on desktops, tablets, and mobile devices alike.

## 🚀 How to Start the App

Because this app uses purely static, vanilla web technologies, there are no dependencies to install or servers to run!

1. Open your terminal or file explorer and navigate to the project directory.
2. Locate the `index.html` file.
3. **Double-click `index.html`** to open it directly in your default web browser.
   - *Alternatively, if you prefer to use a local development server, you can run a simple python server in the directory:* `python3 -m http.server 8000` *and visit `http://localhost:8000` in your browser.*

## 🛠️ Technologies Used
- HTML5
- CSS3 (Variables, Flexbox, Grid, Glassmorphism, Animations)
- JavaScript (ES6+, Fetch API, Promises)
- HackerNews Algolia API
- Google Fonts (Outfit)
